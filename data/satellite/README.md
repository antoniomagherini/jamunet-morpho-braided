## Satellite

This folder contains the various datasets generated and used for this project. 

<code>averages</code> contains the averaged images from the January-April datasets 
\
<code>dataset</code> contains the best image (i.e., the one with least number of ``no-data`` pixels) within the low-flow season of every year
\
<code>dataset_month1</code> contains the images (3 classes) of January across all years
\
<code>dataset_month2</code> contains the images (3 classes) of February across all years
\
<code>dataset_month3</code> contains the images (3 classes) of March across all years
\
<code>dataset_month4</code> contains the images (3 classes) of April across all years
\
<code>original</code> contains the raw satellite images (with 3 classes) exported from Google Earth Engine with no prepocessing applied.
\
<code>preprocessed</code> contains the same images of <code>original</code> after the preprocessing steps (standardization of dimensions and flow direction - still with 3 classes)
